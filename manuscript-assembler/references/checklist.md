# 投稿前自检清单

本 Skill 自动检查带 `[自动]` 标记的项；其余需人工/其他技能完成。

## A. 结构与格式（本 Skill 自动）

- [ ] `[自动]` 标题 ≤75 字符，无标点/数字/缩写
- [ ] `[自动]` 16 项章节顺序完整
- [ ] `[自动]` 摘要段 ≤200 词
- [ ] `[自动]` 摘要段含四段式线索（背景 / 理由 / Here we show / 推进领域）
- [ ] `[自动]` Data Availability 存在
- [ ] `[自动]` Code Availability 存在
- [ ] `[自动]` 每条图注 ≤250 词
- [ ] `[自动]` 小标题 ≤40 字符
- [ ] `[自动]` 参考文献编号连续
- [ ] `[自动]` 参考文献作者 >5 时按 et al. 缩略
- [ ] `[自动]` 正文参考文献 ≤约50 条

## B. 内容（交 nature-writing / 作者）

- [ ] 正文六页≈2500 词 或 八页≈4300 词
- [ ] 展示项 4–6 个
- [ ] 每张图/表在正文被引用
- [ ] 摘要段以 `Here we show` 或等价表述引出主结论
- [ ] 结论面向跨学科读者

## C. 图表（交 nature-figure）

- [ ] 图注以简短标题句开头，不复述结果/方法
- [ ] 图与图注可独立理解
- [ ] 分辨率足够供审稿（首投不要求生产级）
- [ ] Extended Data ≤10 项
- [ ] 每张图的来源数据可溯源

## D. 声明与合规（交 nature-data / nature-statistics）

- [ ] Data Availability 给出仓库/登记号/限制条件
- [ ] Code Availability 给出代码仓库与版本
- [ ] 统计小节透明可复现
- [ ] 报告摘要（life/behavioural/social/ecology 类必需）
- [ ] LLM 使用已在 Methods 或等价章节声明
- [ ] 作者贡献、利益冲突、资助声明齐备

## E. 行政（交作者）

- [ ] 通讯作者用 `*` 标注
- [ ] 全体作者同意作者列表与顺序
- [ ] 同等贡献者（≤3 人）在地址下方标明
- [ ] present address 紧随作者列表
- [ ] 相关在投/在审稿件已披露

## 结论判定

| 结论 | 条件 | 行动 |
|---|---|---|
| `PASS` | 无 ERROR 无 WARN | 可进入人工内容撰写 |
| `REVIEW REQUIRED` | 有 WARN 无 ERROR | 逐条评估 WARN |
| `BLOCKED` | 有 ERROR | 必须修复后重跑 |
